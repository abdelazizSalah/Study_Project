# How to execute Task3
- Task3 is all about creating toolbox to be able to execute all the previous tasks using the command line.

## Important structure note:
- For this script to work you must have the files in this structure:
  - root
    - Assingment1
      - Abdelaziz_Codes
        - Sheet1_codes
      - Anna_Code
      - SDA
    - Assignment2
      - Task1
      - Task2
      - Task3
        - client_alignment_and_candidates.npz
        - server_alignment_and_candidates.npz
- otherwise, you will need to change the directories strings manually.
## How to use
- first install all requirements
  - >pip install -r requirements.txt
> python toolbox.py -h
- This will show in the console all available functionalities, and how to use them.
